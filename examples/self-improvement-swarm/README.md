A swarm of agents that autonomously improve themselves through patchlet generation, verification, and gossip-based propagation.

## Architecture

```
┌──────────────┐     Gossip      ┌──────────────┐
│  Analyzer    │◄───────────────►│  Refactorer  │
│  (patchlet   │                 │  (applies    │
│   generator) │                 │   patchlets) │
└──────┬───────┘                 └──────┬───────┘
       │                                │
       └────────────┬───────────────────┘
                    │
             ┌──────▼───────┐
             │  Orchestrator │
             │  (verifies &  │
             │   promotes)   │
             └──────────────┘
```

## Quick Start

```bash
./launch.sh
```

See [RUNBOOK.md](RUNBOOK.md) for detailed procedures.

## How It Works

- **Patchlets**: Small, verified code changes generated by agents
- **Verification**: Each patchlet is independently verified before application
- **Gossip**: Verified patchlets propagate across the swarm via gossip protocol
- **Exponential decay**: Signal strength decays over time to prevent stale patches
