# arkavo-sat

SAT solver integration for formal TØRG policy analysis and boundary probing.

## Features

- **CNF Extraction**: Automated conversion of TØRG boolean policy graphs to Conjunctive Normal Form (CNF).
- **Boundary Probing**: High-performance detection of inputs near decision boundaries to identify edge cases.
- **Stress Testing**: Comprehensive analysis for identifying policy holes, contradictions, and unsatisfiability.
- **Incremental Analysis**: Optimized modification tracking for fast re-verification of localized policy updates.
- **Probabilistic Probing**: Strategic scheduler for background policy boundary exploration and stress testing.
- **Tseitin Transformation**: Robust implementation of graph-to-logic transformation for formal verification.
