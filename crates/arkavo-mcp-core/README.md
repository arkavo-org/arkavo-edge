# arkavo-mcp-core

Fundamental types and traits for Model Context Protocol (MCP) with minimal dependencies.

## Features

- **Zero-Runtime Dependencies**: Lightweight implementation of core MCP structures for maximum portability.
- **JSON-RPC 2.0 Compliance**: Standard request, response, and error models for MCP communication.
- **Unified Tool Schema**: Fundamental tool definition and execution traits for cross-crate integration.
- **Portable Architecture**: Designed to be the base dependency for all MCP-related components in the ecosystem.
- **Error Handling**: Standardized MCP error codes and structures for consistent failure reporting.
