# arkavo-code-search

Fast code search and structural refactoring tools for Arkavo Edge agents.

## Features

- **High-Performance Search**: Fast repository-wide pattern matching via native ripgrep integration.
- **Structural Refactoring**: Language-aware structural search and replace for complex codebase transformations.
- **AST Parsing**: Precision code analysis and navigation using Tree-sitter for multiple programming languages.
- **Syntax-Aware Capture**: Advanced querying of syntax trees to identify specific code patterns and structures.
- **Multi-Language Support**: Optimized for Rust, Python, JavaScript, TypeScript, and Go.
- **Surgical Code Edits**: Precise node-based position tracking for reliable automated code modifications.
