# arkavo

Main binary for the Arkavo agentic CLI tool.

## Features

- **Agentic CLI**: AI-driven command-line interface for complex software engineering tasks.
- **Multi-Model Orchestration**: Intelligent routing and orchestration across Gemini, Claude, and local LLMs.
- **Context-Aware Interactions**: Long-term memory and project-wide context integration.
- **MCP Extensibility**: Native support for the Model Context Protocol to provide agents with powerful toolsets.
- **Cross-Platform**: Unified experience across macOS, Linux, and Windows environments.
