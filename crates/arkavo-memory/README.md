# arkavo-memory

Local-first, privacy-focused memory service for Arkavo Edge agents.

## Features

- **Semantic Vector Search**: High-performance similarity search using the HNSW (Hierarchical Navigable Small World) algorithm.
- **Embedded Embeddings**: Bundled AllMiniLML6V2 ONNX model for zero-runtime model downloads.
- **Local Persistence**: Durable memory storage with SQLite for long-term context retention.
- **MCP Integration**: Native memory tools for storage, retrieval, and categorization via the Model Context Protocol.
- **Privacy-First Design**: Fully offline operation with no external API calls or data exfiltration.
- **Automatic Categorization**: Intelligent semantic categorization of memories for efficient retrieval.
- **Vector Search Toolset**: Optimized toolkit for managing and querying high-dimensional memory vectors.
