# arkavo-registration

Secure agent registration and decentralized discovery infrastructure.

## Features

- **Cryptographic Onboarding**: Secure challenge-response mechanism for verifying agent identity during registration.
- **Multi-Channel Discovery**: Standardized agent descriptors for registration via QR codes, URLs, or JSON payloads.
- **mDNS Network Registration**: Automated localized discovery and registration of agents on the same network.
- **Portable Identity**: Universal Arkavo agent URLs for seamless setup and peer-to-peer trust establishment.
- **Public Key Management**: Robust tools for extracting and managing agent public keys for secure communication.
- **QR Code Generation**: Integrated support for generating registration QR codes for physical or mobile onboarding.
