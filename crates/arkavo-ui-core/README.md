# arkavo-ui-core

Core UI abstractions and LLM integration for the Arkavo Edge platform.

## Features

- **Unified UI Abstractions**: Standardized traits and types for building agent-driven user interfaces.
- **Dual Engine Support**: High-level adapters for both CEF (Chromium Embedded Framework) and Web-based UIs.
- **LLM Integration**: Direct orchestration of LLM outputs for dynamic UI generation and event handling.
- **Safe Rendering**: Built-in support for HTML escaping and content sanitization in generated interfaces.
- **Event-Driven UI**: Unified model for processing user interactions and agent-driven state updates.
- **Cross-Platform Compatibility**: Portable UI core that works across macOS, Linux, and Windows.
