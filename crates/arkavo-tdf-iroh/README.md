# arkavo-tdf-iroh

Iroh-based P2P data plane for high-performance TDF blob transport.

## Features

- **P2P Blob Transport**: Efficient peer-to-peer data distribution using the Iroh protocol.
- **Content-Addressed Storage**: Reliable and deduplicated blob storage for secure agent communication.
- **Embedded Iroh Node**: Full P2P connectivity support directly within the Arkavo agent runtime.
- **BlobTransport Implementation**: Native implementation of the TDF transport layer for GB-scale data transfer.
- **Direct Peer Fetching**: Optimized ticket-based mechanism for direct data retrieval between agents.
- **Filesystem Persistence**: Optional support for durable, filesystem-backed blob storage.
