# arkavo-protocol

Unified communication protocol adapters for MCP and A2A agent interactions.

## Features

- **mTLS Security**: Full mutual TLS support for secure, authenticated agent-to-agent communication.
- **Dual Protocol Support**: Native implementations for both Model Context Protocol (MCP) and Agent-to-Agent (A2A) protocols.
- **High-Performance Transports**: Robust HTTP and WebSocket transport layers with built-in retry and rate limiting.
- **Automated Discovery**: mDNS-based agent discovery for decentralized networking with zero configuration.
- **JSON-RPC 2.0 Core**: Standardized client/server infrastructure for interoperable agent services.
- **OpenRPC Integration**: Built-in support for OpenRPC schema generation and service discovery.
