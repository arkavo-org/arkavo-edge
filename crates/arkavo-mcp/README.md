# arkavo-mcp

Core trait definitions and types for the Model Context Protocol (MCP) in Arkavo.

## Features

- **Standardized Tool Trait**: Unified interface for implementing and executing extensible agent capabilities.
- **Schema-Driven Discovery**: JSON Schema-based definitions for automated tool discovery and LLM parameter validation.
- **Async Execution**: Fully asynchronous execution model for high-concurrency agent workflows.
- **Protocol Interoperability**: Standardized request/response structures for seamless integration with the wider MCP ecosystem.
- **Lightweight Implementation**: Minimal set of types focused on core protocol compliance and performance.
