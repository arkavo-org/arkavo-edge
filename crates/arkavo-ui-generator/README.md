# arkavo-ui-generator

AI-driven UI code generation with integrated vision-powered verification.

## Features

- **Dynamic UI Generation**: Multi-stage pipeline for generating full HTML/CSS/JS components from prompts.
- **Vision-Powered Verification**: Multimodal LLM validation (Qwen2.5-VL) of generated UI screenshots.
- **Automated Planning**: Intelligent UI decomposition into manageable component plans via LLM orchestration.
- **Screenshot Automation**: Native support for platform-specific window capture and image preprocessing.
- **Multimodal Image Pipeline**: High-performance image processing for vision-enabled edge models.
- **Progressive Streaming**: Real-time generation with incremental progress tracking and feedback.
- **Component Detection**: Automated classification of generated UI elements (forms, charts, tables).
