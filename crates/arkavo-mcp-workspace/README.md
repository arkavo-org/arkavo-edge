# arkavo-workspace

Workspace and project management utilities for Arkavo Edge agents.

## Features

- **Project Management Tool**: Standardized MCP-compliant tool for managing agent working directories.
- **Recursive Discovery**: High-performance directory walking and file listing for large codebases.
- **Process Management**: Integrated utilities for managing subprocess execution within the workspace.
- **Environment Isolation**: Tools for maintaining clean, isolated workspace states for autonomous tasks.
- **Workspace Health**: Built-in monitoring of workspace integrity and resource usage.
- **Dataflow Integration**: Native support for managed workspace operations in complex dataflow pipelines.
