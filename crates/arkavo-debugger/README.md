# arkavo-debugger

Higher-level debugging, diagnostics, and session replay for Arkavo agents.

## Features

- **Session Replay**: Record and replay agent sessions for precise debugging and regression testing.
- **Diagnostics API**: Comprehensive interface for querying agent state and identifying error patterns.
- **Real-Time Health Reporting**: System-wide status monitoring and health checks for agent components.
- **Session Management**: lifecycle tracking for complex, multi-step agent interactions.
- **Forensic Analysis**: Integration with event streams and memory for deep analysis of agent decisions and failures.
