# arkavo-qwen

Qwen-3 (Instruct + Vision) LLM integration for Arkavo Edge via DashScope.

## Features

- **Multimodal Understanding**: Full support for Qwen-VL and Qwen3-VL models for complex image-text tasks.
- **Text & Reasoning**: Integration with the complete Qwen-3 series for advanced instruction following and reasoning.
- **SSE Streaming**: High-performance Server-Sent Events support for real-time text and tool outputs.
- **Regional Deployment**: Native support for International and China region API endpoints.
- **Agent Capability Toolkit**: Built-in infrastructure for tool and function calling with automated validation.
- **Vision Optimization**: Specialized helpers for image encoding, validation, and multi-part message construction.
