# arkavo-crypto

Core cryptographic primitives for secure agent identity and communication.

## Features

- **Agent Keypair Management**: Secure generation and storage of Ed25519 signing keys.
- **Identity Verification**: Robust message signing and signature verification for agent-to-agent interactions.
- **Portable Keys**: Base64 encoding and decoding for easy distribution of agent public keys.
- **Cryptographic Integrity**: Ensures the authenticity and non-repudiation of agent-generated messages.
- **Standardized Identity**: Unified representation of agent cryptographic identities across the Arkavo ecosystem.
