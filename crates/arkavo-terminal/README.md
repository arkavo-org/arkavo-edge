# arkavo-terminal

GPU-accelerated Terminal UI (TUI) for the Arkavo agentic CLI tool.

## Features

- **High-Performance Rendering**: Ratatui-based TUI with GPU-accelerated terminal integration.
- **Multi-Terminal Management**: Concurrent execution and monitoring of multiple agent tasks in a single view.
- **Syntax Highlighting**: Tree-sitter integration for fast, accurate code highlighting across multiple languages.
- **Agent Interactivity**: Native chat interface for real-time interaction with local and remote LLMs.
- **Editor Integration**: Built-in support for Helix and Vim for seamless code editing within the TUI.
- **Live Diff Visualization**: High-performance diff rendering for reviewing agent-suggested code changes.
- **Integrated MCP Status**: Real-time monitoring of Model Context Protocol (MCP) tools and connection health.
