# arkavo-mcp-macos

macOS-specific MCP tools for iOS simulator automation and XCTest integration.

## Features

- **iOS Simulator Management**: Automated tools for booting, listing, and cleaning up iOS simulators.
- **XCUITest Automation**: High-level UI interaction (tap, type, find element) via native XCTest integration.
- **Diagnostic Reporting**: Real-time health checks and diagnostics for simulator services and process state.
- **Non-Interactive Bridge**: Secure, non-interactive UI automation designed for autonomous agent environments.
- **Runner Configuration**: Automated installation and configuration of the XCTest runner on simulated devices.
- **Native Platform Testing**: Precision tools for Apple platform testing and UI validation.
