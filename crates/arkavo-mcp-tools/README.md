# arkavo-mcp-tools

Comprehensive cross-platform MCP tool registry for Arkavo Edge coding agents.

## Features

- **Security & Compliance**: Integrated SAST scanning (Semgrep), vulnerability detection (OSV), and SBOM generation (Syft).
- **GitHub Orchestration**: Automated PR reviews, checks API integration, and issue management tools.
- **Multi-Language Testing**: Unified test runner for pytest, jest, cargo test, and go test.
- **Repository Operations**: High-performance Git and filesystem tools for autonomous codebase manipulation.
- **Context Enrichment**: Web search, time synchronization, and OS-level diagnostics for agent context.
- **TDF Security**: Integrated tools for TDF encryption and secure data transport.
- **Category-Based Discovery**: Intelligent tool categorization for efficient LLM discovery and routing.
