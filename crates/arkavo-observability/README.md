# arkavo-observability

Unified observability infrastructure and structured logging for Arkavo Edge agents.

## Features

- **Structured Logging**: Advanced logging infrastructure with built-in support for session IDs and task correlation.
- **Session-Level Tracing**: Automated tracing of agent interactions from session creation to completion.
- **Health Reporting**: Real-time monitoring and reporting of agent health status and performance metrics.
- **OTLP Integration**: Automated detection and configuration for exporting telemetry to OpenTelemetry collectors.
- **Contextual Metrics**: Collection of task-specific metrics including token usage, latency, and success rates.
- **Zero-Config Detection**: Intelligent auto-configuration of observability layers based on the local environment.
