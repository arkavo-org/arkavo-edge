# arkavo-browser

Browser automation and WebDriver support for Arkavo Edge agents.

## Features

- **Chromium Automation**: Native control of Chromium-based browsers via chromiumoxide.
- **Live DOM Injection**: Real-time manipulation of web pages for agent-driven interactions.
- **WebDriver Integration**: High-level browser control tool compatible with the MCP ecosystem.
- **Asynchronous Interaction**: Fully non-blocking browser operations for responsive agent workflows.
- **Visual Context**: Support for capturing screenshots and page state for multimodal analysis.
