# Archived UI Components

This directory contains UI components that have been deprecated and archived for reference.

## dashboard.html (Maestro)

**Deprecated**: 2025-10-13
**Reason**: Simplified to single blank canvas UI mode

The Maestro dashboard was the original multi-agent orchestration interface featuring:
- Real-time agent discovery and connection status
- Flow visualization with canvas-based agent topology
- Live telemetry stream with metrics
- Agent detail panels with A2A protocol information
- Chat interface for direct agent communication
- Configuration management UI

This interface has been replaced by the blank canvas UI (`shell.html`) which focuses on AI-driven UI generation from natural language prompts. The blank canvas approach aligns with the project's vision of Rust-driven DOM manipulation and future CEF integration (see `../rust-driven-dom-engine.md`).

For historical reference and potential reuse of components, the dashboard HTML is preserved here.
