# Arkavo Edge 1.0 Release - Manual Test Plan

## 1. Introduction

This document outlines the manual testing strategy for the Arkavo Edge 1.0 release. The goal is to ensure the stability, functionality, and user experience of the core features across all supported platforms.

- **Target Version:** 1.0
- **Testing Scope:** Manual execution of test cases covering core CLI commands, agent functionality, Git integration, UI, platform compatibility, and error handling.
- **Target Platforms:**
    - macOS (arm64, Apple Silicon)
    - Linux (x64)
    - Linux (aarch64)

## 2. Prerequisites

### 2.1. Hardware
- Apple Silicon Mac (e.g., M1/M2/M3)
- x64-based Linux machine (or VM)
- aarch64-based Linux machine (e.g., AWS Graviton instance, Raspberry Pi 4/5)

### 2.2. Software
- Git
- Rust and Cargo (latest stable version)
- Xcode Command Line Tools (for macOS)
- An active internet connection

### 2.3. Setup
1. Clone the repository: `git clone <repository_url>`
2. Navigate to the project root: `cd arkavo-edge`
3. Build the release binary: `cargo build --release`
4. The primary executable will be located at `target/release/arkavo`.
